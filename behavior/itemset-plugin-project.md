# Project: Reusable ItemSet Plugin for Walmart Advertising

## Role:
Frontend Lead – Walmart Advertising Platform

## Summary:
In Walmart's ad platform, campaigns are linked to product groups called *itemsets*. These were being managed across multiple apps with duplicated logic and inconsistent rules.

To solve this, I designed and built a **shared Node.js plugin**, published as an internal NPM package, to centralize itemset filtering logic, validation rules, and UI helpers. This plugin is now used across multiple teams to ensure consistency and reduce rework.

## Key Contributions:
- Invented and delivered a **reusable itemset plugin** to standardize how itemsets are created and filtered across apps.
- Enabled **version control, easy configuration, and extensibility**, reducing bugs and speeding up adoption.
- **Refactored the itemset index page UI** to remove duplicate logic and made it generic for reuse in other item views.
- Led frontend design using **modular React components** — lightweight, easy to integrate, and consistent in UX.
- Collaborated with backend teams to align on shared filtering rules and ensure data consistency.

## Impact:
- Adopted by **3+ teams**, reducing duplicate logic and onboarding time.
- Improved code maintainability and testing by centralizing logic.
- Helped deliver faster, more reliable itemset creation across the platform.
